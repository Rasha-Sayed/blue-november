نوفمبر الأزرق – صفحة توعوية

طريقة التشغيل:
1. فك ضغط الملف.
2. افتح index.html في المتصفح.

قبل النشر:
- روابط التواصل الاجتماعي في الفوتر تجريبية (#)، استبدلها بروابط حسابات المنتدى الرسمية.
- يستخدم الموقع Bootstrap وGoogle Fonts وFont Awesome عبر CDN، لذا يلزم الاتصال بالإنترنت.
- تم استخدام شعار المنتدى المرفق في الهيدر وFavicon.
- العداد يحسب تلقائياً الوقت المتبقي حتى 14 نوفمبر القادم.
